# Auto Design

Batch event ID generator by **Troy Auto Design**.

Upload an ID template and an Excel list of names and roles, position the text on the preview, then download every ID as a high-quality image in one click.

## Features

- Upload an ID template (PNG, JPG or WEBP)
- Upload names and roles from Excel or CSV (`Name` and `Role` columns)
- Drag the name and role text into place, with font, size, color and alignment controls
- Long names shrink automatically to fit
- Download one ID, selected IDs, or all IDs as a ZIP file
- Images are saved at the template's full resolution, as PNG or JPG

## Usage

Open `index.html` in a browser, or enable GitHub Pages for this repository (Settings → Pages → Deploy from branch → `main` / root).
